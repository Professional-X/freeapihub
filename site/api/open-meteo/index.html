Key features

  • Hourly and daily weather forecasts up to 16 days
  • Historical weather data back decades
  • Air quality and pollen data
  • Geocoding search for place names
  • No API key required

What can you build?

  • A weather dashboard for a travel planning site
  • Historical climate analysis for a gardening app
  • An air-quality alert widget for smart home dashboards
  • A hiking conditions checker with hourly forecasts
