Key features

  • Top, new, best and ask/show story feeds
  • Full comment trees for every item
  • User profiles with submissions
  • Real-time updated data
  • No API key required

What can you build?

  • Tech news readers with custom filtering
  • Trend trackers for keywords across the community
  • Comment thread analyzers and discussion dashboards
  • Slack or Discord bots posting top stories
